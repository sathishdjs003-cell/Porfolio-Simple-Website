# 🌐 Simple Portfolio Website

This is a basic and clean **portfolio website** created using **HTML** and **basic CSS**.  
The project includes two simple pages — a **Home** page and a **Contact** page — designed to practice web development fundamentals and create a starting point for a personal online portfolio.

---

## 📄 Pages Included
- **Home Page (index.html)**  
  A minimal introduction page with simple layout and text.

- **Contact Page (contact.html)**  
  Contains basic contact information, styled using basic CSS.

---

## 🛠️ Technologies Used
- **HTML5** – for page structure  
- **CSS3** – for simple styling and layout  

No frameworks or JavaScript were used in this project.
